# OpenCart E-Commerce Website: Manual Testing

**Created by:** Gauri Bajare
**Type:** Personal learning project (manual and functional testing)
**Application under test:** OpenCart demo store (https://demo.opencart.com)

## Objective
Test the main customer flows of an e-commerce website by designing test cases, executing them manually, and reporting defects.

## Scope
- User Registration
- Login and Logout
- Product Search
- Shopping Cart
- Checkout (up to order review)

## Approach
- Test cases written in Excel with steps, test data, expected and actual results
- Positive, negative and boundary test cases
- Techniques used: Equivalence Partitioning, Boundary Value Analysis
- Defects documented with steps to reproduce, severity, priority and screenshots
